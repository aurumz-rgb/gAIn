gAIn. Terminal Documentation

Welcome to the official documentation for the gAIn. Stock Market Terminal. This platform provides real-time, mathematically calculated trading targets and news for the Indian Stock Market (NSE/BSE).

Architecture Overview

The application is split into a decoupled Frontend and Backend architecture, allowing for seamless live updates without relying on heavy AI processing for every tick.

  • Frontend (Vercel / GitHub Pages): A pure HTML/JS/CSS file styled as a macOS terminal. It polls the backend every 1 second for live data, renders Markdown text, and draws Plotly charts directly in the browser.
  • Backend (Fly.io / Localhost): Built with Python FastAPI. It acts as the orchestrator, receiving requests, spawning the MCP server, fetching live data, performing the math, and returning a formatted JSON payload.
  • MCP Server (Model Context Protocol): A local Python script (server.py) spawned by the backend. It contains the "Tools" (functions) that fetch Yahoo Finance data, NSE profiles, and Google News RSS feeds.

The Mathematics (Explained Simply)

All math is calculated natively in Python using Pandas to ensure 100% accuracy. No AI hallucination is involved in the numbers.

Short Term Math (24-Hour Data, 5-Minute Intervals)

  • VWAP (Volume Weighted Average Price): The ultimate institutional average price.
    Formula: Cumulative(Price * Volume) / Cumulative(Volume)
    If price is above VWAP, buyers are in control.
  • RSI (Relative Strength Index): Measures the speed and change of price movements.
    Formula: 100 - [100 / (1 + Average Gain / Average Loss)]
    If RSI > 70, the stock is overbought (expensive). If RSI < 30, it is oversold (cheap).
  • Stochastic RSI: Applies the RSI formula to RSI itself to find extreme edges.
    Formula: (Current RSI - Lowest RSI) / (Highest RSI - Lowest RSI)
  • MACD (Moving Average Convergence Divergence): Shows momentum by comparing 12-day and 26-day moving averages.
    Formula: 12-day EMA - 26-day EMA
  • Bollinger Bands: Volatility bands around the price.
    Formula: 20-day SMA +/- (2 * Standard Deviation)
    Price hitting the upper band means it's high; hitting the lower band means it's low.
  • ATR (Average True Range): Measures how much the stock moves up and down daily. Used to calculate Stop Loss.
    Formula: Average of True Range over 14 days

Long Term Math (1-Year Daily Data)

  • 50-DMA & 200-DMA: Simple Moving Averages over 50 and 200 days. If the 50-DMA is above the 200-DMA, it's a long-term uptrend (Golden Cross). If below, it's a downtrend (Death Cross).
  • Fibonacci Retracement: Horizontal lines showing support and resistance levels based on the golden ratio.
    Levels: 0%, 23.6%, 38.2%, 50%, 61.8%, 100%

Predictions (Next 1-3 Hours)

  • 1-Hour Projection: Current Price +/- (0.5 * ATR)
  • 2-Hour Projection: Current Price +/- (1.0 * ATR) + (MACD Momentum * 2)
  • 3-Hour Projection: Tests the 24h Bollinger Band support/resistance levels.

Data Sources

  • Yahoo Finance API: Used for OHLC (Open, High, Low, Close) historical data, real-time prices, and company profiles.
  • NSE India API: Primary source for company sectors and industries.
  • Google News RSS: Scraped live for both Stock-Specific and Global/Macro news (Wars, Economy, Oil Prices).

⚙️ How It Works (Step-by-Step)

  1. User types a ticker (e.g., RELIANCE.NS) in the terminal.
  2. The Frontend sends a POST request to the FastAPI backend and starts a 1-second polling loop.
  3. The Backend starts an MCP Client session and calls the 5 tools: get_company_profile, get_bid_ask_targets, get_long_term_analysis, get_indian_stock_news, and get_global_market_news.
  4. The MCP Server fetches raw data from Yahoo/NSE/Google, runs the Pandas mathematical calculations, and returns JSON.
  5. The Backend formats this JSON into a Markdown string with [CHART:...] tags and sends it back.
  6. The Frontend parses the Markdown, renders the text, and draws the Plotly charts exactly where the tags are placed.
